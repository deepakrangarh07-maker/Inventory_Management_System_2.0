9.23 The LINQ methods you should learn first
Don't try to memorize 50 LINQ methods.
Start with these:	
Method	Purpose	
Where()	Filter	
FirstOrDefault()	Find first matching item	
First()	Find first item	
SingleOrDefault()	Find zero/one item	
OrderBy()	Sort ascending	
OrderByDescending()	Sort descending	
ThenBy()	Secondary sorting	
Select()	Select/transform data	
Count()	Count	
Any()	Check if something exists	
All()	Check every item	
Sum()	Total	
Min()	Minimum	
Max()	Maximum	
Average()	Average	

Most important for YOUR project
Your existing inventory operations can eventually use LINQ like this:
Search by code
var item = items
    .FirstOrDefault(x => x.Code == code);
Search by department
var result = items
    .Where(x => x.Department == department);
Low-stock report
var result = items
    .Where(x => x.CurrentStock <= x.ReorderLevel);
Sort by name
var result = items
    .OrderBy(x => x.Name);
Sort by highest stock
var result = items
    .OrderByDescending(x => x.CurrentStock);
Count items
int totalItems = items.Count();
Check duplicate code
bool exists = items.Any(x => x.Code == code);
Total stock
int totalStock = items.Sum(x => x.CurrentStock);
________________________________________
🧠 One important concept
You will frequently see this:
x => x.CurrentStock <= x.ReorderLevel
For now, read it as:
Take an item x, and check whether its current stock is less than or equal to its reorder level.
The => part is called a Lambda Expression.
So your learning path is actually connected:
LINQ
  ↓
Where()
  ↓
Lambda Expression
  ↓
x => condition
That's why don't worry if the => syntax looks strange right now. We'll properly learn it in Topic 10 — Lambda Expressions.

Now understand the difference
This is the most important part.
For your list:
List<int> numbers = new List<int>
{
    10, 25, 5, 40, 15, 30
};
Where()
Give me all matching items.
var result = numbers.Where(x => x > 20);
→ 25, 40, 30
________________________________________
FirstOrDefault()
Give me the first matching item.
var result = numbers.FirstOrDefault(x => x > 20);
→ 25
________________________________________
Count()
How many items?
var result = numbers.Count();
→ 6
________________________________________
Any()
Does at least one item match?
var result = numbers.Any(x => x == 40);
→ True
________________________________________
Sum()
What's the total?
var result = numbers.Sum();
→ 125
________________________________________
Min()
What's the smallest?
var result = numbers.Min();
→ 5
________________________________________
Max()
What's the largest?
var result = numbers.Max();
→ 40
